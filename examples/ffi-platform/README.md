# Read the process ID

Print the OS, process ID and native long width using the system process library.

Create a project with `lui new Demo --template ffi-platform --sdk <sdk>`. Check it with `lui check Demo/lui.json --mode project --sdk <sdk>`. Build it with `lui build Demo/lui.json --mode headless --sdk <sdk> --output App`.

Run `Start-LUI.exe --stdio --trusted-ffi` on Windows or `./Start-LUI.sh --stdio --trusted-ffi` on Linux.
