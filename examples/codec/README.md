# Codec

Compress or decompress one bounded record on stdin. From a shell with binary redirection, run `lui run lui.json --mode headless --stdio true --providers Compression -- encode gzip < input > output.gz`. Use `decode gzip` to recover the bytes. The other accepted format names are `zlib`, `deflate` and `zstd`. Both the input and the result must fit within 1 MiB. A format or bounds error exits with status 1. Invalid command arguments exit with status 2. The SDK stages the target-specific native declaration and image with this example.
