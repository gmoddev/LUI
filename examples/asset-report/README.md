# Asset report

Copy this complete example from the development SDK. From the copied folder, run the SDK's `lui check` and `lui run --mode headless --diagnostics development`. Edit `Src/Inputs.luau` to supply your settings and asset records. The example emits one JSON report with normalized UTC modification dates, URL-safe download names and Base64 tags. The sample inputs are part of the project. No filesystem, network or UI grant is required. Development diagnostics enable the explicit report print.
